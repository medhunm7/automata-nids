# Application Visual Documentation (Screenshots)

This directory contains placeholders for visual captures of the running Automata-Based Network Intrusion Detection System application interface.

## Screenshots Roster

1. **`01_dashboard_telemetry.png`**  
   *Overview:* Surveillance Dashboard featuring Total Events, Safe Events, Suspicious Events, Detection Accuracy, Live Traffic Telemetry Area Chart, and Protocol Distribution Donut Chart.

2. **`02_automata_engine_status.png`**  
   *Overview:* Deterministic Finite Automaton (DFA) state visualizer illustrating live transition paths: `START -> SYN_SENT -> CONNECTION -> FAILED -> ALERT`.

3. **`03_alerts_management_console.png`**  
   *Overview:* Security Alerts Console showing severity color badges (Critical, High, Medium, Low), multi-column search, severity filtering, CSV export, and alert detail modal.

4. **`04_log_file_upload.png`**  
   *Overview:* Drag-and-drop log ingestion interface supporting CSV, TXT, and JSON files with real-time post-analysis metric breakdown and sample file download buttons.

5. **`05_traffic_analytics_recharts.png`**  
   *Overview:* Deep-dive Recharts analytics page displaying protocol volumes, Daily/Weekly/Monthly trend lines, top attacking source IPs, and top targeted destination ports.

6. **`06_automata_interactive_simulator.png`**  
   *Overview:* Step-by-step interactive FSM testbench with input alphabet symbol triggers and 4 preset attack simulations.

7. **`07_pdf_forensic_report.png`**  
   *Overview:* Generated college assessment forensic PDF report featuring executive summary, telemetry tables, detected incidents, and mitigation recommendations.
